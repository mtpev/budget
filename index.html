mybudget

A personal budgeting tool, built and used by one person for their own accounts.

What it is

mybudget is a private, non-commercial project. It downloads my own bank transactions so I can categorize my spending. It has no other users, is not offered to the public, and has no accounts to sign up for.

What data it uses

Through Plaid, and only for accounts I connect myself, it reads:

  • Account names, types, and the last four digits of account numbers
  • Transactions: date, amount, description, merchant, and category

It does not move money, and it cannot make payments or transfers.

How the data is stored

Data is stored in a local database on my own computer, with file access restricted to my user account. It is not uploaded to any server or cloud service.

Sharing

The data is never sold, shared, or used for advertising. No one other than me has access to it.

Disconnecting

I can remove a bank connection at any time through the app, through my bank, or through Plaid Portal. Removing a connection stops all further data access for that account.
